# Crédits des icônes et des polices

## Font Awesome Free 7.3.1

Les icônes d’interface du site (flèches, téléchargement, enveloppe, trophée,
poignée de main, réseaux sociaux, etc.) sont issues de **Font Awesome Free**,
téléchargées depuis le paquet officiel `@fortawesome/fontawesome-free` publié sur
<https://fontawesome.com/>.

- Icônes : licence **CC BY 4.0** ;
- Polices : licence **SIL OFL 1.1** ;
- Code : licence **MIT**.

Texte complet : `LICENSE-fontawesome.txt`.
Aucune police Font Awesome n’est servie : les tracés officiels sont intégrés au
sprite SVG maison (`tools/icon_data.py`), ce qui évite une requête réseau et un
fichier de police supplémentaire.

## Simple Icons 16.36.0

Les marques technologiques affichées autour du portrait (HTML5, CSS, JavaScript,
React, Vue.js, PHP, Python, Kotlin, Android, Git, GitHub, Linux) proviennent de
**Simple Icons**, paquet officiel `simple-icons`, licence **CC0 1.0**.

Texte complet : `LICENSE-simple-icons.md`.

## Polices du site

- **Plus Jakarta Sans** (titres) — SIL OFL 1.1, `assets/fonts/plus-jakarta-sans-OFL.txt` ;
- **Inter** (textes) — SIL OFL 1.1, `assets/fonts/inter-OFL.txt`.

Les deux familles sont auto-hébergées en version variable, sous-ensemble latin,
avec `font-display: swap`.
